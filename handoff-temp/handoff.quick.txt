First setup steps:

git clone https://github.com/maceip/friscy.git
cd friscy
git lfs pull
bash tools/setup_native_harness.sh

Important:
- Do not assume bundled tarballs are materialized.
- Verify tar assets are not tiny LFS pointer files before using them.

Useful checks:

ls -lh docs_site/codex.tar docs_site/rootfs.tar friscy-bundle/nodejs.tar friscy-bundle/claude-slim.tar
file docs_site/codex.tar docs_site/rootfs.tar friscy-bundle/nodejs.tar friscy-bundle/claude-slim.tar

Native build:

mkdir -p build-native
cd build-native
cmake ../runtime
make -j"$(nproc)"
cd ..

Wasm build:

mkdir -p build-wasm
docker run --rm -v "$PWD":/src emscripten/emsdk:latest bash -lc 'cd /src && cd build-wasm && emcmake cmake ../runtime && emmake make -j$(nproc)'
cp build-wasm/friscy.js friscy-bundle/friscy.js
cp build-wasm/friscy.wasm friscy-bundle/friscy.wasm
