NATIVE BASIC RUNS

Use a real materialized rootfs tar, not an LFS pointer. Examples:
- ./codex.tar if you have one locally materialized
- ./docs_site/rootfs.tar after a successful build/pack
- ./friscy-bundle/nodejs.tar for node-specific testing if materialized

Example commands:

timeout 120 ./build-native/friscy --rootfs ./codex.tar /bin/bash -lc 'echo pre; /bin/node -e "console.log(\"node-ok\")"; echo post'
timeout 120 ./build-native/friscy --rootfs ./codex.tar /bin/bash -lc 'cat > /tmp/basic.js <<'"'"'EOF'"'"'
const nums = [1, 2, 3, 4];
const sum = nums.reduce((a, b) => a + b, 0);
console.log(`sum=${sum}`);
if (sum !== 10) process.exit(1);
EOF
exec /bin/node /tmp/basic.js'
timeout 120 ./build-native/friscy --rootfs ./codex.tar /bin/bash -lc 'cat > /tmp/fetch-aol.js <<'"'"'EOF'"'"'
const url = "https://www.aol.com";
const res = await fetch(url, { redirect: "follow" });
console.log(`status=${res.status}`);
const text = await res.text();
console.log(`bytes=${text.length}`);
console.log(text.slice(0, 80).replace(/\s+/g, " "));
EOF
exec /bin/node /tmp/fetch-aol.js'

If ./codex.tar is absent on your machine, substitute the actual local tar path.

DIFFERENTIAL TRACE

Use a real rootfs tar and a real unpacked qemu rootfs. Do not assume friscy-bundle/rootfs.tar or docs_site/rootfs.tar are materialized unless you verified them.

Example template:

python3 tools/differential-syscall-trace.py \
  --diff-tag repro-node-mmap \
  --friscy-rootfs /absolute/path/to/materialized/rootfs.tar \
  --qemu-rootfs /tmp/friscy-full-rootfs \
  --guest-cmd "/bin/bash -lc 'echo pre; /bin/node -e \"console.log(\\\"node-ok\\\")\"; echo post'" \
  --node-path auto \
  --focused-diff \
  --divergence-window 12 \
  --max-divergences 20 \
  --friscy-bin /absolute/path/to/build-native/friscy \
  --qemu-bin /usr/bin/qemu-riscv64-static \
  --friscy-log /absolute/path/to/repro-node-mmap.friscy.log \
  --qemu-log /absolute/path/to/repro-node-mmap.qemu.log \
  --symbol-root /tmp/friscy-full-rootfs \
  --timeout 120
